# 🚀 PlantMind AI

**AI-Powered Industrial Asset Intelligence Platform**

PlantMind AI is an intelligent industrial asset management platform designed to centralize plant knowledge, monitor equipment health, and assist maintenance teams through AI-powered insights. The platform combines asset monitoring, document management, semantic knowledge graphs, and AI copilots into a unified enterprise dashboard.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/rajanyaganguli/PlantMind-AI.git
```

Move into the project

```bash
cd PlantMind-AI
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
